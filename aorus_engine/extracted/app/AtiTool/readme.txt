Description
===========
AMDVBFLASH is a console and GUI utility for AMD GPU device in a diagnostics environment providing ability to flash the VBIOS.

Software and Hardware Requirements
==================================

Supported OS:
- Microsoft Windows (32bit/64bit)
- UEFI
- Linux
- DOS

Hardware:
- A system equipped with at least one AMD discrete graphics device.


Installation and launch
=======================
AMDVBFLASH is distributed in installer package, which will install all necessary components to support execution of AMDVBFLASH.

Once the installation is completed, shortcuts will be created under "Program Files" menu and desktop. 

Documentation
=============
Console mode options can be viewed on-line by starting AMDVBFLASH from command line or terminal window
with -h options.
Refer amdvbflash_ext_help.txt
